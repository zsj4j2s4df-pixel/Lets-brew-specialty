VAPID-sleutels

voor de push-worker van Lets Brew Specialty

1. sleutelpaar maken

Dit gebeurt volledig in je eigen browser, met de ingebouwde WebCrypto. Er gaat niets naar een server — ook niet naar Cloudflare of naar mij.

2. overnemen in Cloudflare

Deze regel is de privésleutel. Zet 'm in Cloudflare als type Secret, en verder nergens: niet in wrangler.jsonc, niet in een bestand dat je commit, niet in een chat. Raak je 'm kwijt, dan maak je hier gewoon een nieuw paar — je hoeft dan alleen de meldingen in de app één keer opnieuw aan te zetten.

3. waar het heen gaat

  1. Cloudflare-dashboard → Workers & Pages → je worker lets-brew-push → Settings → Variables and Secrets.
  2. Add → type Text, naam VAPID_PUBLIC_KEY, waarde uit het eerste vak.
  3. Add → type Text, naam VAPID_SUBJECT, waarde mailto: plus je eigen e-mailadres.
  4. Add → type Secret, naam VAPID_PRIVATE_JWK, waarde uit het tweede vak.
  5. Deploy.

Sluit deze pagina daarna. Ververs je 'm, dan krijg je een ander paar en klopt de sleutel in Cloudflare niet meer.
